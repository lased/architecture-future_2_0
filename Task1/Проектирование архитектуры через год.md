## **Проектирование архитектуры через год**

### **Архитектура системы через год (Диаграмма контейнеров C4)**
```mermaid
C4Container
title Контейнерная диаграмма модернизированной системы

Person(user, "Пользователь", "Сотрудник или клиент системы")

System_Boundary(system, "Цифровая платформа") {
    Container(client, "Клиентский интерфейс", "React/Web", "Веб-приложение с заменой Power Builder на современный фреймворк")
    Container(api_gw, "API Gateway", "Kubernetes", "Единая точка входа с маршрутизацией запросов")
    Container(ai_services, "ИИ-сервисы", "Python/Golang", "ML-модели для аналитики и прогнозирования")
    Container(fintech, "Финтех-сервисы", "Java", "Платежные системы и страхование")
    Container(medical, "Медицинские сервисы", "Python", "Аналитика EHR данных")
    Container(dwh, "Обновленный DWH", "Snowflake", "Облачное хранилище с автоматизацией ETL")
    Container(bi, "BI-система", "Power BI + Superset", "Витрины данных и кэширование отчетов")
    Container(kafka, "Интеграционная шина", "Kafka", "Асинхронная обработка событий")
    Container(auth, "Аутентификация", "Keycloak", "SSO через OAuth2")
}

Rel(user, client, "Использует", "HTTPS")
Rel(client, auth, "Аутентификация через", "OAuth2")
Rel(client, api_gw, "Отправляет запросы", "REST/JSON")
Rel(api_gw, ai_services, "Маршрутизирует", "gRPC")
Rel(api_gw, fintech, "Маршрутизирует", "REST")
Rel(api_gw, medical, "Маршрутизирует", "HL7/FHIR")
Rel(ai_services, kafka, "Читает события из", "Avro")
Rel(fintech, dwh, "Записывает данные в", "JDBC")
Rel(medical, dwh, "Загружает данные в", "Parquet")
Rel(dwh, bi, "Подает данные в", "SQL")
Rel(bi, kafka, "Кэширует отчеты через", "Kafka Streams")
Rel(kafka, ai_services, "Буферизует данные для", "ML-пайплайнов")
Rel(auth, api_gw, "Проверяет токены через", "JWT")

```
### **Проблемные места и приоритизация (MoSCoW)**

| **Категория** | **Проблема**                     | **Описание**                                     | **Бизнес-эффект**                                     |
| ------------- | -------------------------------- | ------------------------------------------------ | ----------------------------------------------------- |
| **MUST**      | Устаревший DWH                   | SQL Server 2008 не справляется с нагрузкой       | Задержки отчетности → потеря клиентов                 |
| **MUST**      | Ручные трансформации данных      | Большая часть времени уходит на ETL-процессы     | Замедление time-to-market                             |
| **SHOULD**    | Медленная интеграция             | Apache Camel не поддерживает потоковую обработку | Риск потери данных при пиковых нагрузках              |
| **COULD**     | Legacy-интерфейс (Power Builder) | Высокие затраты на поддержку                     | Невозможность быстрого обновления функционала         |
| **WON’T**     | Монолитная архитектура финтеха   | Сложность масштабирования                        | Пока не критично благодаря разделению на микросервисы |
